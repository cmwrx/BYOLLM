    BRING YOUR OWN LLM
    BYOLLM Setup

    Get the skills, install them in your agent, check that it worked.

    1. Get the skills. Download the latest VoiceTalker skills release (the .plugin file and the zip), or use the SKILLS folder in your project. VoiceTalker skills package
    2. Install them in your agent. Open your agent below and follow its steps; copy any command with one tap.
    3. Check that it worked. In a new chat ask the check question.

    Roles

      The VoiceTalker flow

      Six steps, from setup to your first recording.

      A Scribe is your script, split into scenes and short lines, with a voice for each speaker.

      Reference

      1. Every skill saves a new file next to your input and raises the version (my-story-scribe-v1.00.json, then v1.01). Nothing is overwritten.
      2. Basic skills need no Python. Advanced skills need Python 3.8 or later; the screen skills also need Chrome and Pillow, and the video skill ffmpeg.
      3. Subagent skills (soundscape, film-critic, the Codeumentation gap check) run as independent subagents where the agent supports them, and say so when they run inline.
      4. The Scribe is a plain JSON file. Open it in VoiceTalker Studio to voice it, add pictures and sound, and record the MP3 or MP4.
      5. This page keeps your settings in this browser only. It never reads your files and never sends your settings or prompts anywhere; only the fonts load from Google Fonts.
