# Changelog

## 3.2.8 (November 26, 2026), for VoiceTalker 1.08

1. First public release of VoiceTalker Agent Skills in the BYOLLM repository, with a Claude Code marketplace (`byollm`).
2. New: the VoiceTalker Agent Skills app (`app/index.html`, also at https://cmwrx.github.io/BYOLLM/): the menu as a tree, BYOLLM setup and Agent 1 and Agent 2 roles for Claude, ChatGPT, Codex, Gemini, Grok, Copilot or any other LLM, prompts in each agent's call style, a run order, scenario diagrams, Codeumentation and Help with the full VoiceTalker flow.
3. New skill `codeumentation` (menu 17): updates every code and doc file a change touches, then a subagent checks for gaps.
4. New skill `soundscape` (menu 15): a subagent sound designer for a Scribe or a sound brief.
5. `film-critic` (menu 16 and 16B) now runs as a video-critique subagent, with the Siskel & Ebert style balcony review and a review-and-repair loop.
6. The set is 17 skills and a menu. Scenarios 15 to 17 added.
