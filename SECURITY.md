# Security

Report a vulnerability privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue.

Please include the skill or file, the agent you used, the steps to reproduce, and the effect. We acknowledge reports within five business days.

The skills run inside your own AI agent, with that agent's permissions. They never ask for passwords, never type sign-in details, never send messages and never submit forms; the screen-capture skills ask you to sign in by hand. The app stores its settings only in your browser and makes no network requests other than loading fonts.
